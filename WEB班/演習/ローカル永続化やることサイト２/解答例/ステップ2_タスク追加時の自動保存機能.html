📋 確認手順

  1. コンソール確認: F12 → Console → タスク追加時のメッセージを確認
  2. localStorage確認: F12 → Application → Local Storage → 保存データを確認
  3. 永続性テスト: タスク追加 → F5更新 → タスクは消えるがLocal Storageにデータ残存を確認

💡 学習ポイント

  • JSON.stringify(): オブジェクト配列を文字列に変換
  • try-catch: localStorage操作のエラーハンドリング
  • 自動保存: タスク追加と同時にlocalStorageに保存
  • 定数管理: STORAGE_KEYでキー名を統一管理

📝 注意: ステップ2では保存機能のみ実装。ブラウザ更新時のタスク復元はステップ3で実装します。
